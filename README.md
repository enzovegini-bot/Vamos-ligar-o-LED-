# Vamos-ligar-o-LED 

aluno : Enzo Hebling Vegini

decrição : Resumo

A atividade consiste em criar, no Tinkercad, um sistema com Arduino usando um botão como entrada e um LED como saída. Ao pressionar o botão, o Arduino identifica o comando e acende o LED; ao soltá-lo, o LED é apagado. A prática demonstra a integração entre programação e circuito eletrônico em um sistema de IoT.
